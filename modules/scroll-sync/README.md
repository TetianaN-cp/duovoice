# Scroll Sync (minimal module)

A small helper for synchronized scrolling between two containers.
Designed for chat-like interfaces where both panels should stay aligned
and auto-scroll to the bottom when new content arrives.

This module provides:
- auto-scroll to bottom when the user is at the bottom
- pause auto-scroll when the user scrolls up
- synchronized manual scrolling between two containers
- optional mobile mode with a single scroll container

This is a minimal standalone module extracted from a larger system.
