# UI Select (minimal module)

A small standalone component for rendering and managing a custom dropdown selector.
Designed for lightweight interfaces where users choose an option from a styled list.

Features:
- Opens and closes a floating selection card
- Positions the card relative to the trigger element
- Updates selected item state
- Dispatches a `change` event with selected data
- Works with multiple selectors on the same page

This module is intentionally minimal and does **not** represent the full Duo Voice system.
Only safe, standalone UI components are included in this public release.
